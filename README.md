# Eu Concego Jogar - Conselfie

O **Conselfie** é um aplicativo de autonomia fotográfica desenvolvido dentro do ecossistema **Eu Concego Jogar**. 

## Propósito
Diferente de aplicativos que tentam "corrigir" a foto do usuário, o Conselfie atua como um **diretor de fotografia assistente**, fornecendo feedback espacial e descritivo em tempo real para que pessoas cegas ou com baixa visão tenham total controle sobre a captura de:
- Selfies e registros sociais.
- Fotos de documentos (auxílio no enquadramento para biometria).

## Diferenciais
- **Privacidade:** Processamento de imagem local (on-device) para detecção de rosto.
- **Feedback Descritivo:** Não prescreve comportamento (ex: "sorria"), apenas relata o estado (ex: "rosto centralizado", "olhos abertos").
- **Integração:** Salva as fotos diretamente na galeria nativa do Android para uso com ferramentas de acessibilidade do sistema (TalkBack).
- **Simulador de Biometria:** Treinamento de memória muscular para vencer as barreiras de apps bancários inacessíveis.
